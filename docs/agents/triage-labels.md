# 分诊标签

各技能以五个标准分诊角色沟通。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库使用的标签 | 含义 |
| ------------------------- | ---------------- | ---- |
| `needs-triage`            | `needs-triage`   | 待维护者评估 |
| `needs-info`              | `needs-info`     | 等待报告者补充信息 |
| `ready-for-agent`         | `ready-for-agent` | 规格完整，可交给自动化 agent |
| `ready-for-human`         | `ready-for-human` | 需要人工实现 |
| `wontfix`                 | `wontfix`        | 不予处理 |

当技能提到某个角色（例如「打上可交给 agent 的标签」），使用表中对应的标签字符串。

如需改用仓库已有的其它词汇，直接编辑「本仓库使用的标签」一列。
